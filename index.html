La mission oubliée

Un analyste a laissé une mission inachevée dans un dossier. Terminez-la en appliquant les commandes de l'atelier, et retrouvez le drapeau.

But

Explorer l'arborescence, afficher les fichiers cachés, lire les contenus, et corriger les droits pour atteindre le rapport final.

Commandes autorisées

  • pwd où suis-je
  • ls lister ( -a cachés, -l droits )
  • cd entrer dans un dossier ( cd .. remonter )
  • cat lire un fichier
  • chmod changer les droits
  • clear · help

Règle

Pas de sudo. Tout se résout avec les commandes de l'atelier.

Quand vous trouvez le drapeau, copiez-le et soumettez-le sur la plateforme HACKSHADOW.

kali@hackshadow
